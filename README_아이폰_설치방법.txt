50문장만 죽어라 외워라 — iPhone 13 Safari 웹앱 수정본
===================================================

[원본 유지]
- 제공된 「50문장_모바일웹.zip」의 「아이폰_웹앱」을 기준으로 수정했습니다.
- 영어 문장, 한국어 뜻, 내장 MP3, 장면 이미지, 학습 UI/진도 로직은 변경하지 않았습니다.
- MP3는 index.html에 내장되어 있어 별도 MP3 업로드가 필요하지 않습니다.

[수정 내용]
1. iPhone Safari 녹음 형식에 맞춰 audio/mp4를 우선 사용합니다.
2. 마이크 사용 전 HTTPS/보안 연결 및 브라우저 지원 여부를 확인합니다.
3. 마이크 권한 거부/지원 불가 오류 안내를 iPhone 기준으로 수정했습니다.
4. 녹음 스트림 종료 처리 및 빈 녹음 데이터 검사를 보강했습니다.
5. 오프라인 캐시 버전을 올려 이전 파일이 남는 문제를 줄였습니다.

[웹 공개 — GitHub Pages 예시]
1. GitHub 계정에 로그인하고 새 Public 저장소를 만듭니다.
2. 이 폴더의 index.html, sw.js, manifest.webmanifest, icon PNG 4개를
   저장소 최상위(root)에 업로드합니다. 폴더째 올리지 마세요.
3. Settings → Pages → Build and deployment → Deploy from a branch를 선택합니다.
4. Branch: main / (root) → Save를 누릅니다.
5. 배포가 완료되면 표시되는 https://...github.io/.../ 주소로 iPhone Safari에서 접속합니다.
6. Safari 공유 버튼 → '홈 화면에 추가' → 추가를 누릅니다.
7. 앱에서 녹음 버튼을 눌러 마이크 접근을 허용합니다.

[중요]
- file:///Users/... 는 맥북 로컬 경로이므로 아이폰에서 열리지 않습니다.
- 마이크 녹음은 HTTPS에서 테스트하세요. file://로 연 경우 동작을 보장하지 않습니다.
- 인터넷 연결 후 처음 로드되면 앱 화면/내장 MP3가 캐시되어 오프라인 사용이 가능할 수
  있지만, iOS가 저장공간 정리 시 캐시를 삭제할 수 있으므로 영구 보장되지 않습니다.
- 학습 진도는 해당 기기/브라우저에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다.
- 녹음은 현재 열린 화면의 메모리에만 보관되며 새로고침/앱 종료 시 사라집니다.
- 자동 음성 인식/채점은 iOS Safari 지원 여부 및 네트워크 상태에 따라 제한됩니다.
- GitHub Pages의 Public 저장소는 파일이 공개됩니다. 개인정보를 업로드하지 마세요.
- 실제 iPhone 기기에서의 실기 테스트는 별도로 필요합니다.
